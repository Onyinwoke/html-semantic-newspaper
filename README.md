# Assignment 2.6: Semantic Newspaper Page

## Project Overview
This project demonstrates the use of semantic HTML elements to structure a newspaper-style webpage.

## Semantic Elements Used

- `<header>` — Contains the newspaper title.
- `<nav>` — Provides navigation links.
- `<main>` — Holds the primary page content.
- `<section>` — Groups related news stories.
- `<article>` — Represents individual news stories.
- `<aside>` — Displays related content, including most-read stories.
- `<footer>` — Contains contact and copyright information.

## Files Included

- `index.html` — The newspaper webpage.
- `semantic-tree.txt` — A text representation of the HTML structure.
- `newspaper-screenshot.png` — A screenshot of the completed webpage.

## Competency Check

No `<div>` elements were used because the page could be structured with meaningful semantic HTML elements.

## How to View
Open `index.html` in a browser to view the newspaper webpage.
